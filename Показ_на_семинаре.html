Подготовка

  1. Откройте HTML в браузере. Один файл содержит экраны, документы и слайды; интернет для показа не нужен.
  2. Нажмите «Ведущий». Кнопка «Сначала» сбрасывает оба диалога. Выберите начало сценария.
  3. Используйте F11 или кнопку полного экрана. Для показа без служебных элементов нажмите H. F2 открывает панель ведущего.
  4. Перед семинаром проверьте проектор и скачивание одного Word-файла. Для мелкого текста используйте развёрнутый просмотр и масштаб документа.
«Покажем весь путь: как проверить рабочую среду, выбрать плагин, уточнить задачу и получить связанный комплект материалов. Сегодня используем автономную симуляцию с заранее подготовленными ответами».

Как встроено в презентацию

Новая симуляция работает отдельно. На стартовой странице семинара добавлена карточка запуска, а в обеих частях презентации — ссылка «Симуляция ↗». Она открывает HTML в новой вкладке, поэтому место в презентации сохраняется. После демонстрации закройте вкладку или вернитесь к презентации.

Для переноса на другой компьютер достаточно HTML симуляции. Для переходов из презентации сохраните рядом с ним текущую структуру папок part-1 и part-2.

Управление и восстановление

  • F2 — открыть или закрыть панель ведущего.
  • H — скрыть или вернуть верхнее управление.
  • Escape — закрыть окно или просмотр файла.
  • Стрелки ← / → в просмотре презентации переключают слайды.
  • «Следующее действие» сначала подставляет запрос, затем отправляет его. Так ведущий успевает объяснить формулировку.
  • Автопоказ продвигает текущий диалог. Файлы открываются вручную. Любой переход в другой раздел останавливает автопоказ.
  • Выбор этапа семинара открывает подготовленную точку диалога. «Сначала» сбрасывает оба примера.

Файлы Tarbie скачиваются без изменения исходного содержимого. Предпросмотр DOCX адаптирован для браузера. Слайды подготовлены из исходного PPTX. У Ustaz отсутствуют оригиналы результатов, поэтому их карточки открывают скриншоты. Перезагрузка HTML начинает новую демонстрацию.
